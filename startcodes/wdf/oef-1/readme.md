# Oefening 1 — Flexbox

## Doel

Gebruik Flexbox om een layoutstructuur te bouwen.

## Opgave

1. Bouw een pagina met de volgende structuur:
   - Een header die de volledige breedte inneemt
   - Een hoofdgedeelte met een zijbalk (1/3) en een inhoud (2/3) naast elkaar
   - Een footer die de volledige breedte inneemt
2. Gebruik **alleen Flexbox** (geen Grid, geen floats).
3. De zijbalk heeft een andere achtergrondkleur dan de inhoud.
4. Header en footer hebben een donkere achtergrond met witte tekst.

## Tips

- Gebruik `display: flex` op de container.
- Gebruik `flex: 1` en `flex: 2` om de verhouding te bepalen.
- Gebruik `flex-direction: column` voor de buitenste wrapper.
