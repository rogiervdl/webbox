Wat zijn de inschrijvingskosten?

De inschrijvingskosten voor een modeltraject bedragen € 119,40 per academiejaar.

Wanneer start het academiejaar?

Het academiejaar start in de tweede week van september.

Hoe schrijf ik me in?
