Demo header

Deze header heeft veel tekst. Met een vaste hoogte zal bij smalle schermen een deel van de tekst onderaan buiten de header vallen. Dit is uiteraard niet de bedoeling! Dit passen we aan, door te werken met een flexibele hoogte, waarbij we in plaats van een vaste hoogte een minimum hoogte instellen. Om af te werken maken we de padding wat groter bij bredere schermen.
