## Opdracht

Zet de figuren op een lijn; de springers hangen bovenaan.

1. Maak de flex-container; geef het een hoogte van 200px.
2. Zet 50px ruimte tussen de kolommen.
3. Aligneer alle afbeeldingen onderaan met `align-items`.
4. Aligneer de springende figuren bovenaan met `align-self`.
