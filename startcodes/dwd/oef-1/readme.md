# Oefening 1 — Tabellen

## Doel

Maak een HTML-pagina met een tabel die de volgende gegevens toont.

## Opgave

1. Maak een tabel met een koprol (`<thead>`) en een gegevensgedeelte (`<tbody>`).
2. De tabel heeft vier kolommen: **Naam**, **Voornaam**, **Leeftijd** en **Stad**.
3. Voeg minstens vijf rijen met fictieve gegevens toe.
4. Geef de tabel een rand via CSS.
5. Zorg dat elke even rij een andere achtergrondkleur krijgt.
