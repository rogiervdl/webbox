## Opdracht

Gegeven een array van studenten met naam en punten. Gebruik array-methodes om de volgende info in de console te tonen:

1. alle namen (met `map()`)
2. de geslaagde studenten — punten >= 10 (met `filter()`)
3. het gemiddelde, afgerond op 1 decimaal (met `reduce()`)
4. de student met de hoogste score (met `reduce()`)

Gebruik `const`, string interpolatie en arrow functions.
