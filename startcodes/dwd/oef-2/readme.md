# Oefening 2 — Formulieren

## Doel

Maak een HTML-formulier met verschillende invoervelden.

## Opgave

1. Maak een formulier met de volgende velden:
   - Naam (tekstveld, verplicht)
   - E-mail (e-mailveld, verplicht)
   - Geboortedatum (datumveld)
   - Geslacht (radiobuttons: Man / Vrouw / Andere)
   - Interesses (checkboxes: Sport / Muziek / Lezen / Reizen)
   - Opmerking (textarea)
2. Voeg een verzendknop toe.
3. Stijl het formulier zodat labels en invoervelden netjes uitgelijnd zijn.

## Tips

- Gebruik `<label for="...">` om labels te koppelen aan invoervelden.
- Gebruik `required` voor verplichte velden.
