## Opdracht

Alle output komt in de console. De juiste namen van de events vind je in de [lijst van events](https://rogiervdl.github.io/JS-course/02_domhtml.html#soorten-events).

1. Bij klik op de eerste button log `'er is op button 1 geklikt'`.
2. Bij klik op de tweede button log `'er is op button 2 geklikt'`.
3. Bij selectie van een waarde uit de dropdown, log een bericht `'nieuwe waarde gekozen'`.
4. Als de muis over de afbeelding komt, log een bericht `'muis over de afbeelding'`.
5. Als de muis de afbeelding weer verlaat, log een bericht `'muis uit de afbeelding'`.

*tip: inspecteer de HTML om de juiste selectors te vinden: voor de eerste button is dit `'.btn-1'`, voor de dropdown `'select'` enz...*
