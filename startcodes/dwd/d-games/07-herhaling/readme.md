## Opdracht

Maak een mini-app om een naam op te slaan en te kopiëren:

1. laad bij het openen van de pagina de bewaarde naam uit localStorage en toon die
2. bij klik op *Opslaan*: bewaar de naam in localStorage en toon die
3. bij klik op *Kopiëren*: kopieer de naam naar het klembord via de Clipboard API

Gebruik `localStorage` (getItem/setItem) en `navigator.clipboard.writeText` (async/await).
