## Opdracht

Maak een kleurenpalet met donkere modus:

1. initialiseer het preview-vlak met de kleur van de actieve li (via `dataset`)
2. bij klik op een kleur: markeer die als actief (via `classList`), pas de achtergrond van het preview-vlak aan via de `style` property, en toon de naam
3. bij klik op de knop: schakel donkere modus in/uit via `classList.toggle` op `document.body`; pas ook de knoptekst aan

Gebruik `classList`, `style`, `dataset` en `this` in event handlers.
