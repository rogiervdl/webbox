# WebBox

This project uses the `js-app-rmp` architecture. Always follow that skill when writing or editing JavaScript.

Always follow the `js-base` skill when writing or editing JavaScript.

Always follow the `css-base` skill when writing or editing CSS.

Always follow the `html-base` skill when writing or editing HTML.

## Beperkingen

- Geen npm, geen bundler — de app draait rechtstreeks als statische site.
- Geen ES modules — Monaco's AMD-loader is niet compatibel.

## Deployment

- Gehost op GitHub Pages via de `gh-pages` branch.
